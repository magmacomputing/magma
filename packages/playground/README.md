# Tempo Playground

Interactive Vite + TypeScript playground for [@magmacomputing/tempo](https://github.com/magmacomputing/magma).

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/magmacomputing/tempo-playground?file=src%2Fmain.ts)

## Quick Start

```bash
npm install
npm run dev
```

> **Note**: This repository is mirrored from `packages/playground` in the [magma](https://github.com/magmacomputing/magma) monorepo.
