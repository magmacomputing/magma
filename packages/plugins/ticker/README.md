# @magmacomputing/tempo-plugin-ticker (Documentation Scaffold)

> [!NOTE]
> This directory is intentionally empty and serves exclusively as a documentation harvesting scaffold.

The real, functional code for the `ticker` plugin is maintained internally in `tempo-workspace/packages/ticker`. 

This directory exists solely so that the monorepo's documentation generation pipeline can harvest the `doc/` files found here and integrate them into the global GitHub Pages VitePress site. When published to npm, the actual source code and binaries are injected from the private workspace.
