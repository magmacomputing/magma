    • format

    Function format

    Formats a supported date-time value using a named format, template, or internationalization options. Scoped day/week time fields count wall-clock units from local midnight or Monday, independent of offset transitions. The roman modifier converts integers 1-3999 and leaves other values unchanged.

    Param: obj

    The value to format; omitted values use the current date and time.

    Param: fmt

    A registered format name or literal format template.

    Param: options

    Formatting and configuration overrides.

    Returns

    The formatted date-time string, a format proxy when no format or options are supplied, or an empty string when a format is supplied and the resolved value is not a ZonedDateTime.

    Throws

    Error when a requested dialect formatter is unavailable. Temporal input conversion errors, formatter or custom token callback errors, and Intl errors when no fallback succeeds also propagate.
