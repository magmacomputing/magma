    Class WeakCache<K, V>

    WeakCache

    Map-like cache holding values weakly via WeakRef and auto-pruning collected entries using Finalizer without memory leaks.

    Keys must be primitive (string | number | symbol) to ensure the key does not create a strong reference cycle with the cached value.
