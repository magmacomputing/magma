    Class Reactive<T>

    Reactive

    Universal, zero-dependency async reactive stream combining push-based event emission and pull-based AsyncIterable iteration with native TC39 resource management (using / await using) and Garbage Collection finalization safety.

    Example

    const stream = new Reactive<number>();

    // Consumer 1: Pull-mode
    queueMicrotask(async () => {
      const val = await stream.pull(); // 42
    });

    // Producer: Push-mode
    stream.push(42);
