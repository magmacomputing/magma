    Class WebStore

    Wrapper around local / session Browser Storage. Refactored for lazy-initialization to ensure side-effect free imports.

    Example

    const store = WebStore.local;
    store.set('user', { id: 1, name: 'Alice' });
    const user = store.get('user');
