# 📜 Version 5.x History

## [v5.0.0] - 2026-11-28

### 🚀 Key Highlights & Developer Experience

Tempo **v5.0.0** is a clean-break modernization of the Tempo date-time engine. It introduces the dedicated **`tempo-kit`** and **`@tempo-kit/*`** package namespace, shifts `Tempo.now()` to an immutable `Tempo` instance factory, separates universal Civic Terms from opt-in Fiscal and standalone Cultural plugins, and brings TC39 Signal reactivity across the ecosystem.

> [!NOTE]
> **Summary of Highlights**
> - **New `tempo-kit` & `@tempo-kit/*` Namespace**: `import { Tempo } from 'tempo-kit'` (or `'tempo-kit/core'` for the bare-bones tree-shakeable kernel) paired with `@tempo-kit/plugin-*` ecosystem packages.
> - **`Tempo.now()` Returns an Immutable `Tempo`**: `Tempo.now({ timeZone })` now returns a full `Tempo` instance; raw epoch numbers live on `Tempo.epoch.{ns,ms,us,ss}` and native `Temporal.Instant` on `Tempo.instant`.
> - **`Tempo.derive()` Prototypal Sandboxes**: Isolated subclass sandboxes with `Symbol.dispose` (`using`) resource cleanup.
> - **Civic, Fiscal & Cultural Terms Split**: `CivicTerms` (`QuarterTerm`, `SeasonTerm`, `TimelineTerm`) ship pre-loaded in `tempo-kit`; `FiscalTerm` is opt-in via `tempo-kit/terms`; `ZodiacTerm` and `EasternTerm` now live in [`@tempo-kit/plugin-cultural`](https://www.npmjs.com/package/@tempo-kit/plugin-cultural).
> - **Encapsulated `.span` Metrics**: Range-based Terms expose `{ start, end, total, elapsed, remaining, progress }` under `.span` with lazy memoized duration/progress getters and cached boundary instances.
> - **Format Token Rationalization**: `{ww}` is reclaimed for calendar week of year (matching SQL `WW`), `{wom}` adds week of month, `{yow}` / `{woy}` represent ISO week-numbering year/week, and `:compact` replaces legacy fused modifiers.

### 🌟 New Features & Developer Guide

#### 1. `tempo-kit` & Modular Subpaths
Install the core package and only the plugins you need:
```typescript
import { Tempo } from 'tempo-kit';

const now = Tempo.now({ timeZone: 'Australia/Sydney' });
console.log(now.term.quarter.key);         // 'Q4'
console.log(now.term.quarter.span.progress);
```

For minimal bundles, use `tempo-kit/core` and opt in selectively:
```typescript
import { Tempo } from 'tempo-kit/core';
import { CivicTerms, FiscalTerm } from 'tempo-kit/terms';

Tempo.use(CivicTerms);
Tempo.use(FiscalTerm);
```

#### 2. Isolated Sandboxes with `Tempo.derive()`
Create scoped `Tempo` configurations without mutating the global singleton:
```typescript
import { Tempo } from 'tempo-kit';

{
  using Sandbox = Tempo.derive({ locale: 'fr-FR', timeZone: 'Europe/Paris' });
  const t = Sandbox.now();
  console.log(t.format('{wkd} {dd} {mon}'));
}
```

#### 3. Standalone Ecosystem Plugins (`@tempo-kit/plugin-*`)
* **`@tempo-kit/plugin-cultural`**: `ZodiacTerm` and `EasternTerm` (Chinese/Japanese/Korean/Vietnamese lunar zodiac variants).
* **`@tempo-kit/plugin-dialects`**: Moment, Day.js, Luxon, POSIX `strftime`, Go, PHP, and Oracle SQL format compatibility.
* **`@tempo-kit/plugin-signals`**: TC39 Signals integration (`toRelativeSignal`, `intervalSignal`, `watchSystem`).

For full upgrade details, see the [v4 → v5 Migration Guide](../migration-guide).
